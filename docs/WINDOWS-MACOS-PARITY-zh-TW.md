# Windows／macOS 行為一致性規格

Windows 版以 macOS 版為行為基準。平台 UI 技術不同，但角色狀態、時間、
速度、精靈編號及功能優先順序應保持一致。

## 共用狀態與精靈

| 編號 | 狀態 |
|---:|---|
| 0 | 爬行 A |
| 1 | 爬行 B／進食 |
| 2 | 攀爬 |
| 3 | 懸掛／拖曳 |
| 4 | 猴式蹲伏／喊爸 |
| 5 | 跳躍 |
| 6 | 坐下 |
| 7 | 睡眠 |

## 核心參數

- 更新頻率：60 FPS。
- 障礙物重新掃描：每 0.35 秒。
- 重力：每秒 28 點速度變化；Windows 因 Y 軸向下而使用正值。
- 跳躍週期：角色年齡每 11 秒進入一次跳躍窗口。
- 跳躍保護：特殊跳躍至少間隔 1.4 秒。
- 休息週期：每 17 秒中的第 14～16 秒。
- 特殊姿勢保持：0.65 秒。
- 餵食接近速度：每秒 165 點。
- 開始進食距離：86 點。
- 進食時間：2.4 秒。
- 喊爸下降速度：每秒 720 點。
- 喊爸顯示時間：2 秒。
- 爆炸淡出：0.65 秒。

## 功能優先順序

1. 拖曳中的角色固定使用編號 3，停止物理及其他動畫。
2. 喊爸下降期間，未被拖曳的角色固定使用編號 4；必須等待所有角色落底。
3. 喊爸顯示期間，全員固定使用編號 4。
4. 有食物目標時，角色優先前往食物並進食。
5. 暫停時停止普通行為。
6. 其餘時間執行普通重力、跳躍、休息、螢幕及視窗碰撞。

## 平台原生差異

- macOS：AppKit、選單列、Core Graphics 視窗資料。
- Windows：WPF、通知區、Win32 `EnumWindows`。
- macOS 使用 Vision 偵測臉部；Windows 使用本機影像區域分析。
- Windows 多螢幕若使用不同 DPI，Win32 像素與 WPF 座標仍需實機驗證。
